# Guide Utilisateur - YouTube Kids

## 🎯 Bienvenue !

YouTube Kids est une application qui permet aux parents de créer une bibliothèque de vidéos YouTube sécurisée pour leurs enfants. Seules les vidéos que vous ajoutez seront visibles par vos enfants.

---

## 📱 Premier Lancement

### Étape 1 : Création du Code PIN

Lors du premier lancement, l'application vous demandera de créer un code PIN à 4 chiffres :

1. **Entrez un code PIN** (4 chiffres, par exemple : 1234)
2. **Confirmez le code PIN** (re-saisissez les 4 mêmes chiffres)
3. **Mémorisez ce code !** Il protège l'accès à l'administration

⚠️ **Important** : Si vous oubliez le code PIN, vous devrez réinstaller l'application et perdrez toutes les vidéos ajoutées.

### Étape 2 : Ajouter Vos Premières Vidéos

Une fois le PIN créé, l'interface d'administration s'ouvre automatiquement :

1. Cliquez sur le bouton **+** (en bas à droite)
2. Allez sur YouTube depuis votre navigateur ou l'app YouTube
3. Trouvez une vidéo que vous souhaitez ajouter
4. Cliquez sur **Partager** → **Copier le lien**
5. Revenez dans YouTube Kids et collez le lien
6. Cliquez sur **Ajouter**

La vidéo apparaît maintenant dans la bibliothèque !

---

## 🎨 Interface Enfant

C'est l'écran que votre enfant verra et utilisera.

### Caractéristiques

- **Grandes vignettes colorées** avec l'image de la vidéo
- **Titre lisible** en gros caractères
- **Durée de la vidéo** affichée sur chaque vignette
- **Navigation simple** : scroll vers le bas pour voir plus de vidéos

### Utilisation

1. **Lire une vidéo** : Taper sur n'importe quelle vignette
2. **Pendant la lecture** :
   - Play/Pause avec les boutons à l'écran
   - Bouton **Retour** en haut à gauche pour revenir à la liste
   - L'écran se met automatiquement en mode paysage

### Sécurité

- Aucun bouton d'administration n'est visible
- Impossible de sortir de l'application sans le code PIN
- Pas de liens externes vers YouTube.com
- Pas de suggestions de vidéos externes

---

## 🔐 Accéder à l'Administration

### Comment ouvrir le panneau admin ?

1. Depuis l'écran principal (interface enfant)
2. **Appuyez longuement (3 secondes)** sur le **coin supérieur droit** de l'écran
3. Une fenêtre vous demandera le code PIN
4. Entrez votre code PIN à 4 chiffres
5. L'interface d'administration s'ouvre

💡 **Astuce** : Ce geste est volontairement discret pour que les enfants ne le découvrent pas facilement.

---

## ⚙️ Interface d'Administration

C'est votre panneau de contrôle pour gérer les vidéos.

### Ajouter une Vidéo Unique

1. Cliquez sur le bouton **+** (en bas à droite)
2. Dans le champ, collez le lien YouTube :
   - Format classique : `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
   - Format court : `https://youtu.be/dQw4w9WgXcQ`
3. Cliquez sur **Ajouter**
4. Un aperçu s'affiche avec la vignette et le titre
5. La vidéo est automatiquement ajoutée à la bibliothèque

### Ajouter une Playlist Complète

Vous pouvez ajouter toutes les vidéos d'une playlist YouTube en une seule fois !

1. Sur YouTube, ouvrez une playlist
2. Cliquez sur **Partager** → **Copier le lien**
   - Format : `https://www.youtube.com/playlist?list=PLxxxxxx`
3. Collez le lien dans YouTube Kids
4. Cliquez sur **Ajouter**
5. L'application détecte automatiquement qu'il s'agit d'une playlist
6. Message : "Playlist détectée : X vidéos"
7. Toutes les vidéos de la playlist sont ajoutées automatiquement

### Supprimer une Vidéo

1. Dans la liste admin, trouvez la vidéo à supprimer
2. Cliquez sur l'icône **Poubelle** (🗑️) à droite
3. Confirmez la suppression
4. La vidéo disparaît de la bibliothèque (visible aussi par l'enfant)

### Fermer l'Administration

- Cliquez sur la flèche **←** en haut à gauche
- Vous revenez à l'interface enfant

## ❓ Questions Fréquentes (FAQ)

### 1. Mes enfants peuvent-ils ajouter des vidéos ?

**Non.** Seule l'interface admin permet d'ajouter des vidéos, et elle est protégée par un code PIN. L'interface enfant ne propose aucun moyen d'ajouter du contenu.

### 2. Les vidéos sont-elles téléchargées sur l'appareil ?

**Non.** Les vidéos sont lues en streaming depuis YouTube. Seules les informations (titre, vignette, lien) sont stockées localement.

**Conséquence** : Une connexion Internet est nécessaire pour regarder les vidéos.

### 3. Y a-t-il des publicités ?

Cela dépend des vidéos YouTube. Si la vidéo originale contient des publicités, elles apparaîtront. L'application ne peut pas les supprimer (cela violerait les conditions d'utilisation de YouTube).

**Solution** : Privilégier des chaînes sans publicité ou utiliser YouTube Premium.

### 4. Combien de vidéos puis-je ajouter ?

Il n'y a **aucune limite** imposée par l'application. Vous pouvez ajouter autant de vidéos que vous le souhaitez.

**Note** : L'application utilise l'API YouTube qui a une limite de 10,000 requêtes par jour, mais cela permet d'ajouter plusieurs centaines de vidéos quotidiennement.

### 5. Les vidéos sont-elles synchronisées entre appareils ?

**Non.** Toutes les données sont stockées localement sur chaque appareil. Si vous utilisez l'application sur plusieurs tablettes, vous devrez ajouter les vidéos sur chacune.

### 6. Que se passe-t-il si j'oublie le code PIN ?

Si vous oubliez le code PIN, la seule solution est :

1. Aller dans **Paramètres Android** → **Applications**
2. Trouver **YouTube Kids**
3. Cliquer sur **Stockage** → **Effacer les données**
4. Relancer l'application

⚠️ **Attention** : Cette action supprimera **toutes les vidéos** ajoutées. Vous devrez recréer votre bibliothèque.

### 7. Comment changer le code PIN ?

Actuellement, pour changer le code PIN :

1. Suivez la procédure "PIN oublié" ci-dessus
2. Créez un nouveau code PIN
3. Rajoutez vos vidéos

*Note : Une fonctionnalité "Changer le PIN" pourra être ajoutée dans une future version.*

### 8. Une vidéo ne se charge pas, que faire ?

**Vérifications** :
1. **Connexion Internet** : Vérifiez que l'appareil est connecté
2. **Vidéo disponible** : La vidéo peut avoir été supprimée ou rendue privée par son créateur
3. **Clé API** : Si aucune vidéo ne se charge, il peut y avoir un problème de configuration (contactez le développeur)

**Solution** : Supprimer la vidéo et en ajouter une autre.

### 9. L'application fonctionne-t-elle hors ligne ?

**Partiellement** :
- **Interface** : Vous pouvez ouvrir l'app et voir la liste de vidéos
- **Lecture** : Nécessite une connexion Internet (streaming YouTube)
- **Ajout de vidéos** : Nécessite une connexion Internet (récupération des informations)

### 10. Puis-je utiliser l'application sur tablette ?

**Oui !** L'application fonctionne parfaitement sur tablettes Android.

Pour une meilleure expérience sur tablette, vous pouvez modifier le nombre de colonnes (nécessite une modification du code - voir README technique).

## 🚨 Résolution de Problèmes

### Problème : "Code PIN incorrect" alors que je suis sûr du code

**Causes possibles** :
- Erreur de frappe
- Le code a été modifié par erreur

**Solution** :
Effacer les données de l'application (voir FAQ #6)

### Problème : "Lien YouTube invalide"

**Vérifications** :
- Le lien copié est complet
- C'est bien un lien YouTube (youtube.com ou youtu.be)
- La vidéo n'est pas privée

**Exemple de lien valide** :
```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
```

### Problème : L'application se ferme toute seule (crash)

**Solutions** :
1. Redémarrer l'application
2. Redémarrer l'appareil
3. Vider le cache : Paramètres → Applications → YouTube Kids → Stockage → Vider le cache
4. Si le problème persiste, contacter le support

### Problème : Les vignettes ne s'affichent pas

**Causes** :
- Connexion Internet lente
- Problème de cache

**Solutions** :
1. Vérifier la connexion Internet
2. Fermer et rouvrir l'application
3. Vider le cache de l'application

## 💡 Conseils d'Utilisation

### Pour les Parents

1. **Prévisualisez les vidéos** : Regardez toujours les vidéos sur YouTube avant de les ajouter à la bibliothèque
2. **Créez des thématiques** : Organisez mentalement vos vidéos par thème (éducation, divertissement, musique)
3. **Limitez la quantité** : Trop de choix peut être contre-productif. Commencez avec 10-20 vidéos
4. **Renouvelez régulièrement** : Supprimez les vidéos qui ne plaisent plus et ajoutez-en de nouvelles
5. **Testez avec votre enfant** : Regardez les premières vidéos ensemble pour vous assurer qu'elles conviennent

### Pour une Utilisation Sécurisée

1. **Ne partagez pas le code PIN** avec vos enfants
2. **Utilisez un code non évident** (évitez 0000, 1234)
3. **Vérifiez régulièrement** la bibliothèque pour vous assurer qu'aucune vidéo inappropriée ne s'est glissée
4. **Accompagnez les jeunes enfants** lors des premières utilisations

### Optimisation

1. **Connexion WiFi** : Privilégiez le WiFi pour éviter la consommation de données mobiles
2. **Qualité vidéo** : YouTube adapte automatiquement la qualité selon votre connexion
3. **Mode Ne Pas Déranger** : Activez ce mode Android pour éviter les notifications pendant l'utilisation
