═══════════════════════════════════════════════════════════════════
              📱 COMMENT GÉNÉRER L'APK (3 MÉTHODES)
═══════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────┐
│ MÉTHODE 1 : ANDROID STUDIO (⭐ RECOMMANDÉ)                      │
└─────────────────────────────────────────────────────────────────┘

  Temps total : ~25 minutes (première fois)

  1. Télécharger Android Studio
     → https://developer.android.com/studio

  2. Ouvrir le projet
     File → Open → Sélectionner le dossier "YTKids"

  3. Attendre la synchronisation Gradle (5 minutes)

  4. Configurer la clé API YouTube
     Éditer local.properties et ajouter :
     YOUTUBE_API_KEY=VotreCléAPIIci

  5. Générer l'APK
     Build → Build Bundle(s) / APK(s) → Build APK(s)

  6. Récupérer l'APK
     app/build/outputs/apk/debug/app-debug.apk

  ✅ Avantages : Simple, interface graphique, idéal débutants

┌─────────────────────────────────────────────────────────────────┐
│ MÉTHODE 2 : LIGNE DE COMMANDE                                  │
└─────────────────────────────────────────────────────────────────┘

  Linux/Mac :
    chmod +x build.sh
    ./build.sh

  Windows :
    build.bat

  ✅ Avantages : Rapide, automatique, pour développeurs

┌─────────────────────────────────────────────────────────────────┐
│ MÉTHODE 3 : GRADLE DIRECT                                      │
└─────────────────────────────────────────────────────────────────┘

  ./gradlew assembleDebug

  ✅ Avantages : Contrôle total, pour experts
